# Zone Analyst for Windows

The website in its own window, working offline. This is an Electron shell
around the `website/` folder: the pages are the same files the site serves,
and `main.js` only opens the window and sends links to other sites to your
browser.

## Download

From the [latest release](https://github.com/Apurba94/zone-analyst/releases/latest):

| File | What it does |
|---|---|
| `Zone-Analyst-Setup.exe` | Installs for your Windows account, with a Start menu shortcut and an uninstaller. You can choose the folder. |
| `Zone-Analyst-Portable.exe` | Runs without installing, from any folder or a USB stick. Starts a little slower. |

Windows 10 or 11, 64-bit. The app has no paid code-signing certificate, so
SmartScreen may say it doesn't recognise it: choose **More info → Run anyway**.

## Build it yourself

Needs [Node.js](https://nodejs.org) 22 or newer. In a terminal in this folder:

```bat
npm install
npm start          :: run from the source, reading ..\website directly
npm run dist       :: dist\Zone-Analyst-Setup.exe and dist\Zone-Analyst-Portable.exe
```

`npm run dist` copies `..\website` into the app as `resources\website`, so
rebuild after changing the site.

## Files

| File | Role |
|---|---|
| `main.js` | The window: one instance at a time, external links open in the browser, adds `ZoneAnalystApp` to the user agent so the home page hides its "Get the app" section |
| `package.json` → `"build"` | electron-builder settings: app id, installer options, output names, which site files to bundle |
| `build/icon.ico`, `build/icon.png` | Drawn by `scripts/make_app_icons.py` from the site's favicon |

`build/icon.ico` is generated by the script rather than by electron-builder,
whose own converter fails on some locked-down Windows machines with
`WebAssembly.Memory(): could not allocate memory`.
